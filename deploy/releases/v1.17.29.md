Добавлен майнинг **Pearl (PRL, pearlhash)** на видеокартах через SRBMiner-MULTI.

- В настройках GPU-майнера выбирается программа: **lolMiner** (по умолчанию, Tari CR29 — как раньше) или **SRBMiner** (Pearl). Старые `miner.json` без нового поля продолжают работать на lolMiner.
- Установка GPU-майнера в консоли умеет ставить SRBMiner-MULTI с GitHub (doktor83/SRBMiner-Multi). Каталог по умолчанию `C:\mining\srbminer`.
- Аргументы SRBMiner: `--disable-cpu --algorithm-gpu pearlhash --pool host:port --wallet address/worker --api-enable`. Старт/стоп/пауза/watchdog работают с обоими майнерами; **xmrig стоп GPU не трогает**.
- Economics читает Kryptex PRL (`prl.kryptex.network`) по реальным выплатам и берёт цену CoinGecko (`pearl-2`). XTM и PRL считаются отдельно.
- На узлах с RTX 2060 SUPER / 3060 / 4060. **RX 6500 XT Pearl не поддерживает** — оставить CR29 или другой алгоритм lolMiner.

Обновление консоли: `mining-fleet update`. **Агенты нужно обновить тоже** — поддержка SRBMiner живёт в агенте.

Живой запуск pearlhash и сравнение с CR29 по выплатам — после полевого теста; калькуляторы на этом флоте уже завышали доход.

Вложения: консоль и агент для Windows x64, full и light, имена xmrig-fleet и SHA-256. Light требует .NET 10.
