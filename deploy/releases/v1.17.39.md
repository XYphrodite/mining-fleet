# mining-fleet v1.17.39

- **Общий доход с каждой машины за всё время (24/7 Agent + Console, с нуля)**:
  - **Непрерывный учёт на стороне агента ([`LifetimeTracker`](../../src/MiningFleet.Agent/LifetimeTrackerService.cs), [`NodeLifetimeDto`](../../src/MiningFleet.Contracts/Dtos.cs))**: фоновый сервис агента каждые 15 секунд интегрирует реальные хеши CPU (`H`), наработку GPU по пулам/алгоритмам (`hashrate-days`) и потреблённую электроэнергию (`kWh`) с атомарным сохранением в `lifetime.json` (файл защищён от перезаписи при будущих `upgrade-agents` и устойчив к уходу ПК в сон).
  - **Сверка и хранение истории в консоли ([`LifetimeIncomeLedger`](../../src/MiningFleet.Console/LifetimeIncome.cs))**: консоль сохраняет накопленные монеты (`XMR`, `PRL`, `XTM` и др.) и `kWh` по каждой машине в `lifetime-income.json` рядом с `fleet.json` (без хранения адресов кошельков), фиксируя сложность на момент начисления, не теряя хеши при временной недоступности API пулов и сохраняя историю даже для временно выключенных узлов или после переустановки ОС на ноде.
  - **Отображение на экранах `Economics`, `Dashboard` и в CLI ([`EconomicsScreen`](../../src/MiningFleet.Console/Ui/EconomicsScreen.cs), [`Dashboard`](../../src/MiningFleet.Console/Ui/Dashboard.cs), [`Cli`](../../src/MiningFleet.Console/Cli.cs))**: добавлена сводная таблица `All-time per node` с суммарными монетами, разбивкой CPU / GPU, общим доходом, электроэнергией (`kWh` и стоимость) и чистой прибылью по каждой машине, а также колонка `All-time` и итоговая строка за всё время на живом дашборде.
