# mining-fleet v1.17.41

- **Точечные исключения Windows Defender по полному пути и автоочистка ([`WindowsDefenderExclusions`](../../src/MiningFleet.Agent/WindowsDefenderExclusions.cs), [`InstallerService`](../../src/MiningFleet.Agent/InstallerService.cs), [`GpuInstallerService`](../../src/MiningFleet.Agent/GpuInstallerService.cs), [`MinerInventoryService`](../../src/MiningFleet.Agent/MinerInventoryService.cs))**:
  - **Защита от маскировки сторонних майнеров**: при установке или обновлении XMRig, lolMiner и SRBMiner-MULTI агент больше не добавляет глобальное исключение процесса по короткому имени (`xmrig.exe`, `SRBMiner-MULTI.exe`, `lolMiner.exe`), из-за которого Microsoft Defender игнорировал одноимённые файлы в любых папках (`Temp`, `AppData` и др.). Вместо этого до распаковки регистрируется `-ExclusionPath` на целевую директорию, а после распаковки — `-ExclusionProcess` строго по полному пути к распакованному исполняемому файлу (с автоматическим удалением устаревшего исключения по короткому имени).
  - **Очистка исключений при удалении майнера**: при вызове удаления (`UninstallAsync`) агент автоматически убирает из Microsoft Defender как саму удалённую папку, так и все зарегистрированные внутри неё пути и процессы.
