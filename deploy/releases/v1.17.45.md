# mining-fleet v1.17.45

- **Поддержка параметров разгона и фиксации частот GPU (`gpuMiner.extraArgs`) с автосбросом при остановке майнера**:
  - В [`GpuMinerSettingsDto`](../../src/MiningFleet.Contracts/Dtos.cs), [`AgentOptions`](../../src/MiningFleet.Agent/AgentOptions.cs) и [`FleetConfig`](../../src/MiningFleet.Console/FleetConfig.cs) добавлено поле `extraArgs` для передачи индивидуальных флагов GPU-майнеру на конкретной ноде (например, `--gpu-cclock0`, `--gpu-coffset0`, `--gpu-plimit0` для `SRBMiner-MULTI` в режиме `P2` на картах NVIDIA Turing).
  - В [`GpuMinerService`](../../src/MiningFleet.Agent/GpuMinerService.cs) добавлена фильтрация специфичных для `SRBMiner` флагов `--gpu-*` при переключении ноды на `lolMiner`, чтобы смена монеты не приводила к ошибке неизвестного аргумента.
  - Добавлен модуль [`NvidiaOcReset`](../../src/MiningFleet.Agent/NvidiaOcReset.cs): при остановке GPU-майнера (в том числе при игровой паузе [`GpuPauseService`](../../src/MiningFleet.Agent/GpuPauseService.cs)) агент через `nvml.dll` автоматически сбрасывает смещения частот ядра и памяти (`P0`/`P2`), снимает фиксацию частот (`ResetGpuLockedClocks`) и возвращает штатный Power Limit видеокарты.
