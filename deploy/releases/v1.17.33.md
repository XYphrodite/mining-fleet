# mining-fleet v1.17.33

- **Меню `Install / update` и `Remove miner`**: добавлен отдельный пункт **`Install / update SRBMiner (GPU, Pearl)`** прямо в меню `Install / update` (рядом с `Install / update lolMiner (GPU, Tari CR29)`), а также пункт **`SRBMiner (GPU, Pearl)`** в меню `Remove miner`.
- **Настройка GPU (`GPU: fleet defaults` / `GPU: per-node settings`)**: при указании алгоритма `pearlhash` автоматически выбирается бинарник `SRBMiner` (`GpuMinerSoftware.SrMiner`).
