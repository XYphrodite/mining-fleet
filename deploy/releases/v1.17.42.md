# mining-fleet v1.17.42

- **Мгновенное открытие `Fleet dashboard` и главного меню ([`Dashboard`](../../src/MiningFleet.Console/Ui/Dashboard.cs), [`FleetService`](../../src/MiningFleet.Console/FleetService.cs), [`Program`](../../src/MiningFleet.Console/Program.cs), [`Cli`](../../src/MiningFleet.Console/Cli.cs))**:
  - **Мгновенный первый кадр и потоковое обновление узлов**: таблица `Fleet dashboard` теперь рисуется сразу при входе (`polling...`) вместо ожидания завершения всех сетевых запросов, а ответы живых узлов отображаются по мере прихода (`~0.15–0.35 с` по Tailscale), не блокируясь на выключенных машинах; выход по любой клавише срабатывает мгновенно в любой момент.
  - **Параллельная фоновая загрузка пулов и курсов ([`MarketService`](../../src/MiningFleet.Console/MarketService.cs), [`GpuPoolService`](../../src/MiningFleet.Console/GpuPoolService.cs), [`XtmIncomeService`](../../src/MiningFleet.Console/XtmIncomeService.cs))**: запросы к HashVault, Kryptex (`balance`/`payouts`/`stats`), LuckyPool, CoinGecko и `/api/v1/config` узлов переведены в параллельный неблокирующий режим с дедупликацией одновременных чтений `/pool/stats`.
  - **Неблокирующая проверка обновлений на старте и команда `mining-fleet dashboard`**: фоновая проверка GitHub Releases больше не задерживает показ главного меню на 4 секунды при недоступности `api.github.com`, а новая CLI-команда `mining-fleet dashboard` открывает живой дашборд напрямую.
