# mining-fleet v1.17.34

- **Быстрое переключение монеты / алгоритма GPU на ноде (`Switch GPU coin / algorithm...`)**:
  - В меню `Miner control → GPU mining...` и `Miner control → Settings...` добавлен пункт **`Switch GPU coin / algorithm...`**.
  - Позволяет в пару нажатий переключить выбранные ноды между **`Pearl (PRL) — pearlhash (SRBMiner)`**, **`Tari (XTM) — CR29 (lolMiner)`** и **`Nexa (NEXA) — NEXA (lolMiner)`**.
  - Автоматически подтягивает и запоминает в `fleet.json` (`gpuProfiles`) пул и адрес кошелька для каждой монеты из конфигов фермы и живых нод, подставляет суффикс `/имя_ноды` и предлагает сразу перезапустить GPU-майнер.
- **Автопоиск бинарника при смене GPU-майнера ([`GpuMinerService.ResolveExecutable`](../../src/MiningFleet.Agent/GpuMinerService.cs))**:
  - Если на ноде установлены оба майнера (`lolMiner` и `SRBMiner-MULTI`), при переключении `Miner` без переустановки агент автоматически находит нужный `.exe` в соседней/стандартной папке (`srbminer` ↔ `lolMiner`), не пытаясь запустить старый бинарник с чужими аргументами.
