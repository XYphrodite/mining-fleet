# mining-fleet v1.17.35

- **Автоматическое добавление майнеров в исключения Windows Defender ([`WindowsDefenderExclusions`](../../src/MiningFleet.Agent/WindowsDefenderExclusions.cs))**:
  - Перед распаковкой и запуском CPU (`xmrig`) и GPU (`lolMiner`, `SRBMiner-MULTI`) майнеров агент автоматически регистрирует целевую папку (`ExclusionPath`) и исполняемые файлы (`ExclusionProcess`) в исключениях Microsoft Defender (`Add-MpPreference`), предотвращая блокировку запуска с ошибкой *«Операция не была успешно завершена, так как файл содержит вирус или потенциально нежелательную программу»*.
- **Безопасное удаление майнера по фактическому пути процесса ([`MinerInventoryService.UninstallAsync`](../../src/MiningFleet.Agent/MinerInventoryService.cs))**:
  - Перед остановкой майнера при удалении агент сверяет путь реального запущенного процесса (`RunningExecutablePath()`), чтобы тесты и проверка сторонних директорий не затрагивали работающий процесс майнера.
- **Инвариантное форматирование чисел в панели дохода ([`XtmIncomePanel`](../../src/MiningFleet.Console/Ui/XtmIncomePanel.cs))**:
  - Исправлено форматирование дробных чисел (`FormattableString.Invariant`) на системах с русской локалью (`ru-RU`).
